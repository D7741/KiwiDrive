# AI Tools Used

## Tools

### Claude (Anthropic)
- Primary AI assistant throughout the project
- Used for architecture planning, code generation, debugging, and documentation
- Helped design the Repository Pattern + Service Layer architecture
- Generated initial model classes, DTOs, and controller structures
- Assisted with JWT authentication implementation
- Generated the conponents design for Frontend
- Helped debug streak logic and CORS issues
- Generated specs documentation

### Claude Code (Anthropic)
- Used directly inside VS Code for in-editor assistance
- Real-time code suggestions and refactoring
- Helped identify security vulnerabilities (missing [Authorize] attributes)
- Used for fixing bugs and improving code quality

### GitHub Copilot
- Used for autocomplete suggestions during coding
- Helped with repetitive patterns (e.g. mapping DTOs)

---

## How AI Was Used Responsibly

- All AI-generated code was reviewed and understood before committing
- AI suggestions were critically evaluated - not blindly accepted
- When AI gave incorrect advice (e.g. wrong package versions), it was corrected
- AI was used to accelerate development, not replace understanding
- All design decisions were made by the developer, with AI providing options and trade-offs
- Bugs found by AI were understood and fixed properly, not just patched

---

## What AI Was NOT Used For

- Final architecture decisions (those were made by the developer)
- Understanding of the codebase (developer maintains full understanding)
- Submitting work without review
